# Thunder Manutenção – Cimbessul

App instalável (PWA) de acompanhamento do Plano de Manutenção e do Plano de Lubrificação – Cimbessul, Paranaguá.

- Site estático, sem build. Publicação na Vercel: Framework Preset **Other**.
- Instalação no celular: Android (Chrome) → "Instalar app"; iPhone (Safari) → Compartilhar → "Adicionar à Tela de Início".
- Execução das OS simulada (demonstração).
